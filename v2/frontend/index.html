Query Schema

Query Schema — one studio for your entire database

Query Schema is an online database client and SQL editor. Connect a PostgreSQL, MySQL, SQL Server or SQLite database and work with it from the browser: browse and edit table data, run SQL with schema-aware autocomplete, build queries visually, read your schema as an ER diagram, schedule reports, and share results with your team.

Databases that are not exposed to the internet stay reachable through a small local agent that runs inside your own network, so you never open a port or allow-list an IP address.

What you can do with it

  • Browse, filter and edit table data, and undo a change from the audit log
  • Write SQL with autocomplete that knows your tables and columns
  • Build a query visually when you would rather not write SQL
  • See relationships as an ER diagram and document the schema
  • Schedule a query, email the result as CSV, or alert on a threshold
  • Take pg_dump backups and export migrations
  • Give teammates per-table roles, row filters and masked columns

Questions

Which databases are supported?

PostgreSQL, MySQL, SQL Server and SQLite.

Do I have to expose my database to the internet?

No — the local agent connects outward from your own network, so a database on a private network needs no open port and no IP allow-list.

Can a query run on a schedule?

Yes — on a cron schedule in the timezone you pick, emailed as a table plus a CSV attachment, and optionally only when a condition is met, with a cooldown so a flapping check cannot spam you.
